| Maintainer | Affiliation | Responsibilities |
| --- | --- | --- |
| [@cleverom](https://github.com/cleverom) | TREFT LTD | All areas; security maintainer; releases; conduct reports |

Slotlock currently has one maintainer. [GOVERNANCE.md](./GOVERNANCE.md) sets out how decisions that
normally need two maintainer approvals are made until a second maintainer joins.

## Contacting the maintainers

- **Security vulnerabilities:** GitHub private vulnerability reporting, as described in
  [SECURITY.md](./SECURITY.md). Never a public issue.
- **Code of conduct concerns:** [clever.eziogor@pylota.io](mailto:clever.eziogor@pylota.io), as described in
  [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md#reporting).
- **Everything else:** an issue or discussion on
  [github.com/PILOTAAI/slotlock](https://github.com/PILOTAAI/slotlock).

## Becoming a maintainer

Maintainer status is earned through sustained, constructive contributions and granted as described
in [GOVERNANCE.md](./GOVERNANCE.md). New maintainers are added to this file in the same pull request
that records the decision.
